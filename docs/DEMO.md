# Демо 90 секунд

Задача: жюри/куратор за 90 секунд видит ценность. Запись экрана длиной больше — не досматривают.

## Сценарий (90 сек)

| Секунды | Действие | Что говорим |
|---|---|---|
| 0:00–0:10 | **Ввод с примером.** Видно 2–3 заполненных поля, не пустой инпут. Вводим «SQL-курсовая, пет-проект на React» | «Обычно студент не знает, с чего начать — поэтому мы начинаем не с пустого поля, а с примера» |
| 0:10–0:30 | **Топ-5.** Показываем 5 карточек. Кликаем одну → раскрывается «что сделано» | «Пятёрка формируется не по оценке, а по тому, что реально сделано. Каждая карточка — это проект» |
| 0:30–1:00 | **План.** Переход на маршрут: 3 шага к пробелу, сроку и «кто проверит» | «Дальше не список «чего не умеешь», а маршрут: вот три шага, вот срок, вот кто проверит» |
| 1:00–1:25 | **Один вопрос консультанту.** Задаём в чат один вопрос, показываем ответ, он привязан к карточке | «Спросить можно что угодно, и ответ приклеен к карточке проекта — видно, на чём он основан» |
| 1:25–1:30 | **Дисклеймер** в кадре + закрытие | «Помогает собрать портфолио. Это не трудоустройство» |

## Правила записи

- Мышь — крупная, курсор виден. Клики — пауза 0,5 сек.
- **Ни одного стопа.** Загрузка, спиннер, «503» — обрезаем, перезаписываем.
- Звук: только голос, без музыки. Шум вентилятора — переписать.
- Один дубль на сцену, если сбился — начинать заново, не склеивать.
- Итог: 1080p, до 2 минут, файл `docs/demo.mp4` + ссылка в README.

## Запасной вариант

Если живое демо не собралось (нет сети, сломался экран, презентация без экрана):

1. Включаем **запись** — это основной сценарий, снятый заранее.
2. Голосом идём по тем же 4 шагам, пока идёт видео. Расхождение голоса и картинки минимально — сценарий один и тот же.
3. Если и видео нет — показываем **3 скрина**: ввод с примером, топ-5, маршрут. Это 20 секунд и всё ещё понятно.

Запасной вариант — норма, а не провал. В демо лучше 20 секунд честных скринов, чем 90 секунд ожидания.

## Чек-лист «не сломать показ»

Перед выступлением:

- [ ] На демо-профиле **нет** заглушек: картинки «no image», «Lorem ipsum», отладочных ID, тестовых email (`test@test`), «User1 / Admin»
- [ ] Все 5 карточек топ-5 реально открываются (клик по каждой, не только по первой)
- [ ] В вопросе консультанту ответ привязан к карточке — и эта связка видна на экране
- [ ] Дисклеймер виден в кадре, а не спрятан в подвале
- [ ] В консоли браузера нет красного — проверь вкладку Network, вкладку Console
- [ ] **Куратор/жюри видят карточку не сломанной без интернета**: проверить на мобильном интернете
- [ ] Шрифт читаем с 3 метров, текст не меньше 14 px
- [ ] Записано 3 дубля, лучший — в отдельном файле
- [ ] Презентация открыта без интернета, видео — отдельным файлом локально (не YouTube-ссылка)
- [ ] Заряжен ноутбук, 100%, провод взял, экран не спит

## Если всё сломалось (30 секунд, не паникуя)

Говорим вслух: «Покажем на скринах, основная ценность вот в чём» → открываем 3 скрина → объясняем маршрут голосом по UX.md §3. Зал держит внимание на голосе, а не на курсоре.
## Интро-сцена в демо (v5, v17)

Сцена 4.2 с показывается при КАЖДОМ открытии главной: полная загрузка/reload,
client-side переход с другой страницы, back/forward (включая возврат из bfcache).
Посекундный делёж:

| Секунды | Кадр |
|---|---|
| 0–1.72 | лис «Идея» (208 px, мобайл 176) бежит диагональным галопом: 4 ноги по суставам, боб тела, противофаза головы, волна хвоста из 2 суставов |
| 1.72–1.86 | прыжок-дуга на знак, squash-посадка, пыль под лапами |
| 1.74–2.14 | знак «СИ» отвечает импульсом, лис осваивается (взгляд, тик ушей, дрожь усов) |
| 2.16–3.06 | блик знака (transform-шиммер, голубо-сине-фиолет) |
| до 4.2 | лис дышит, хвост и уши в idle, вуаль гаснет → панельки |

Управление: «Пропустить» (кнопка/Esc/клик/колесо/тач-свайп).
Клик по кнопке/ссылке под сценой закрывает её и срабатывает; клик по пустому
месту — только закрывает.
Отключить на текущем открытии — `?intro=0`; при
`prefers-reduced-motion: reduce` сцена не показывается.

Демо-выбор: для пересъёмки дубля просто обнови главную — сцена повторится.
Если нужен тихий кадр, открой `/?intro=0` (флаг действует на текущий URL;
после перезагрузки без флага сцена снова покажется). Застревание исключено
страховочным таймером: сцена закроется автоматически, даже если шрифты не грузятся.

Свежий блок «Проверь, что понял» живёт в конце плана на 30 дней: CHOICE-карточка
(варианты — дословные строки из базы ролей, вход лесенкой 60 ms) и SELF-«объясни
своими словами» с кнопкой «Показать ориентир». Это не тест: без счёта, без
красного, повтор безлимитный. Отличный кадр для жюри между «недели» и «забрать
карту (PDF)».

Микро-моушн (v5) должен быть виден в записи: блик на CTA при наведении,
пружина галочек при отметке недель, лесенка входа карточек. Печать PDF и
`prefers-reduced-motion` остаются абсолютно статичными.

## v6 в кадре (копейки к 90-секундке)

1. План: раскрой строку «Проверить» под пунктом «Закрыть пробел «CSS»» →
   мини-карточка (лесенка вариантов), клик верного варианта → поп «✓
   Разобрался». Неверный вариант — подсказка «как в базе», без красного.
   Это лучший кадр на «каждый пункт проверяется».
2. Консультант: клик чипа «План большой?» → ответ лесенкой строк + CTA
   «Открыть план → неделя 1». Вторая ветка — словами «А зарплата будет?» →
   guard-памятка честности (не обещаем трудоустройство). Бейдж «скриптовый
   режим» и подпись «текст не уходит в сеть» — произнести вслух.
3. Декор: карточка навыков на index делает один оборот conic-дуги
   (12 s, если страница открыта > 12 s — дуга возвращается в старт и замирает
   по контракту). Фон страницы несёт едва заметную плёнку (noise 64px), шапка
   — статичный световой блик. Результат/план лишены вращений — только цифры.

## v7 в кадре (21 специальность и «Карта тем»)

1. Не-IT профиль: на index выбери из второго ряда «Уход», «Бухучёт», «Право»
   → «Показать мои направления →». На `/result` в топе окажется специальность
   (чип «специальность»), ниже — «Показать все N направлений»: раскрываются
   остальные из 12. Одна фраза вслух: «в базе 5 ролей и 21 специальность
   колледжа, лимит рекомендаций — до 12».
2. `План на 30 дней` → блок «Карта тем»: центр — направление, лучи — недели,
   вокруг — темы. Клик по узлу «CSS» или «Уход за пациентами» → панель с той же
   мини-проверкой (без счёта и красного), затем «Открыть в плане →» —
   аккордеон раскрывается, страница подскролливается к пункту. Это кадр на
   «каждый шаг проверяем и видим карту целиком».
3. Печать: `Ctrl+P` из плана — карта и мини-строки скрыты, план статичен;
   при `prefers-reduced-motion` все переходы мгновенные. Бюджет анимаций не
   вырос: новых `@keyframes` в v7 — ноль.
