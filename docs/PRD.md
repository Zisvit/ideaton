# PRD: Карьерный трекер (SUPERNOVA №9)

## Цель
Веб-сервис для студентов: ввод профиля → топ-5 карьерных траекторий → 30-дневный план → чат-консультант для уточнений.

## Пользователь
Студент 3–4 курса / недавний выпускник, не знает, куда идти после вуза. Хочет конкретные шаги, а не абстрактные советы.

## Что выдаём (MVP)
1. **Профиль** — навыки, интересы, ценности, опыт (10–15 мин заполнения).
2. **Скоринг** — rule-based матчинг на 50+ ролях из `data/roles`, выдача топ-5 траекторий с обоснованием.
3. **План 30 дней** — по неделям: курсы, проекты, нетворкинг, портфолио. Конкретные действия с дедлайнами.
4. **Чат-консультант** — LLM (kill-switch): уточняет план, отвечает на вопросы, не галлюцинирует факты (роли, навыки из базы).

## Что НЕ делаем (запреты заказчика)
1. **Нет векторного поиска / pgvector** — только детерминированный rule-based скоринг.
2. **Нет генерации контента LLM** — LLM только как интерфейс (чат), факты берутся из `data/roles`.
3. **Нет авторизации / аккаунтов в MVP** — сессия в localStorage, план сохраняется локально.

## Критерии готовности MVP
- [ ] Профиль собирается за ≤15 мин, валидация на фронте.
- [ ] Скоринг возвращает топ-5 за ≤500 мс, детерминированно.
- [ ] План 30 дней: 4 недели × 3–5 действий, каждое — конкретный ресурс/действие.
- [ ] Чат отвечает на вопросы по плану/ролям, не выходит за базу знаний.
- [ ] Запуск одной командой: `docker compose up -d` (web + api + contracts).
- [ ] Контракты (OpenAPI/TypeScript) в `packages/contracts`, версиями.
