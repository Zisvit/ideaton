# UX: язык продукта

Аудитория: студенты колледжа 2–4 курса, куратор, жюри хакатона.
Правило: говорим **как с наставником в кабинете**, не как как система оценки.

## 1. Пять ролей — по одной фразе

| Роль | Фраза для интерфейса |
|---|---|
| **Студент** | «Ты в самом начале — это нормально, сейчас разберёмся» |
| **Куратор** | «Ты за месяц сделал X — вот где это видно» |
| **Работодатель / партнёр** | «Смотрю, кто уже умеет делать вот это» |
| **Преподаватель** | «Класс в целом готов, осталось двое — вот их карточки» |
| **Жюри хакатона** | «Смотрю не на оценку, а на то, что реально сделано» |

Формула: **что сделано → что дальше**. Никогда «что не умеешь» (см. §4).

## 2. Пустые состояния

Пустой экран — не ошибка, а первый шаг. Всегда: короткая фраза + пример + одна кнопка.

| Экран | Текст | Кнопка |
|---|---|---|
| Нет профиля | «Пока пусто. Начни с одного проекта — это 5 минут» | «Добавить первый проект» |
| Нет оценок | «Оценок пока нет. Раздел откроется, когда куратор посмотрит проект» | «Попросить разбор» |
| Пустой топ | «Пока никто не опубликовал проекты. Будь первым — твой проект попадёт сюда» | «Опубликовать проект» |
| Нет пробела-маршрута | «Маршрут соберётся, когда появятся оценки. Пока можно посмотреть примеры» | «Посмотреть примеры» |
| Поиск ничего не нашёл | «Ничего не нашлось. Попробуй имя или навык покороче» | «Очистить поиск» |

Правила: без слова «Ошибка», без заглавных букв в начале фразы-объяснения, без «данных нет». Одна кнопка — одна главная.

## 3. Карточка пробела — что показываем

Не «уровень 2 из 5», а маршрут:

1. **Название** — «Что прокачать» (не «Дефицит компетенций»)
2. **Зачем это** — одна строка: «Без этого не берут на стажировку по фронту»
3. **Маршрут из 3 шагов** — обязательно с конкретикой: «SQL → docker-compose → деплой»
4. **Сколько займёт** — «~2 недели по 4 ч в неделю»
5. **Кто проверит** — «куратор Аня, после 3 проектов»

Каждый пробел обязан давать маршрут. Пробел без маршрута — это ярлык «ты плохой». Не показываем.

## 4. Мягкие формулировки пробелов

| Не пишем | Пишем |
|---|---|
| «Чего не умеешь» | «Что изучить» |
| «Дефицит навыков» | «Следующий шаг» |
| «Не соответствует требованиям» | «Для этого нужно ещё» |
| «Пробел» (в требовании) | «Маршрут» |
| «Слабый уровень: 2/10» | «Базовый уровень — есть база, идём дальше» |
| «Не готов к работе» | «Уже на пути, осталось 2 шага» |
| «Ошибка: нет данных» | «Пока пусто — это начало» |

Запрещено: красный, «❌», «провален», «слабый», «не умеешь» — в любом виде, включая тултипы и подписи графиков.

## 5. Дисклеймеры

Один и тот же текст, в трёх местах: первый заход, экспорт резюме, печать.

> Это не трудоустройство. Карьерный трекер показывает, что вы уже умеете и что можно прокачать — решение о найме принимает работодатель сам. Данные не передаются третьим лицам.

Короткая версия для футера: «Помогаем собрать портфолио, не трудоустройство.»

Дисклеймер **виден до первого результата**, а не спрятан в подвал. Один раз показали — дальше не мешает.

## 6. Тон ответов

- Ты/вы — «ты». Обращение на «вы» = ощущение бюрократии.
- Ошибка → что сломалось + как починить, в одно предложение. «Не нашли — попробуй короче».
- Нет вины. Оценка — про навык, не про человека.
- Максимум 2 предложения на экран. Длинный текст = не прочитали.
- Числа — с контекстом: не «60%», а «6 из 10 проектов закрыто».
- Никаких восклицательных знаков. «Молодец» — ок, «ТЫ МОЖЕШЬ!» — нет.
- Успех: «Готово. Топ-5 обновился» вместо «Поздравляем!!!».

## 7. Холодный старт

Риск №1. Правила первого 3 минут:

- Первый экран: **пример**, а не пустой инпут. «Вот как выглядит заполненный проект — повтори за 5 минут».
- Кнопка «Заполнить примером» — профиль собирается за один клик, дальше можно переписать.
- Демо-данные в первый вход, не в сервере.
- Не спрашивать всё сразу. Максимум 3 вопроса за сессию, остальное — потом.
## 8. Тишина на базе — шедевр в сценах (v4)

Пользовательский запрос «безумный моушн» согласован советом так: безумие живёт
в сценах, база остаётся тихой. Правило страницы: **максимум три сцены движения,
иначе страница читается как цирк.**

Сцены (вне счётчика повседневных микровзаимодействий):

1. **Интро-сцена** (первый показ за сессию, на `/`): лис «Идея» пробегает,
   встаёт на знак «СИ», знак переливается голубо-сине-фиолетовым, слой
   раскрывается в панели. 3.2 с, скип кнопкой/Esc/кликом, страховка — JS-таймер
   (не `animationend`: под prefers-reduced-motion анимации гасятся глобально и
   event не придёт никогда). Скролл под оверлеем не блокируется.
2. **Фоновый слой** (все страницы): aurora из 3 radial-градиентов без blur +
   микро-фигуры (круг/линия/капсула) в role-цветах, opacity ≤ .12, дрейф 30–42 с.
   Это текстура, не фишка: только transform/opacity, reduced-motion замирает.
3. **Конфетти** плана — палитра интро (голубой/фиолет), оранжевый остаётся
   только семантикой «пробела».

Запрещено на внутренних страницах: новые `@keyframes` (кроме перечисленных
сцен), автоиграющие анимации на элементах ввода, blur/box-shadow в анимации
(paint на каждом кадре), счётчики «прогресса квиза» — проверка понимания
отображается без процентов и красного (см. «Проверь, что понял», план).

Вуза-бренд: интро рисует **проектный знак** и талисмана проекта, не «официальный
логотип СИУЭиП» (брендбука в репо нет). Не имитировать эмблемы и гербы.
